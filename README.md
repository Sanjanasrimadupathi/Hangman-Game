# 🎮 Hangman Game

## 📌 Project Description

Hangman is a simple word-guessing game developed using Python. The player tries to guess a randomly selected hidden word by entering one letter at a time. Correct guesses reveal the letters in their positions, while incorrect guesses increase the number of wrong guesses.

The player has a maximum of **6 wrong guesses**. The game ends when the player successfully guesses the complete word or reaches the maximum number of wrong guesses.

This project demonstrates basic Python programming concepts such as loops, conditional statements, functions, strings, lists, user input, and randomization.

## ✨ Features

* 🎲 Randomly selects a word from a predefined list.
* 🔤 Allows the player to guess one letter at a time.
* ✅ Reveals correctly guessed letters.
* ❌ Counts incorrect guesses.
* 🔁 Prevents repeated letter guesses.
* ⚠️ Validates user input.
* 🏆 Displays a congratulations message when the word is guessed.
* 💡 Displays the correct word when the player runs out of attempts.

## 📝 Words Used

The game randomly selects one word from these five predefined words:

* `python`
* `computer`
* `program`
* `keyboard`
* `internet`

## ▶️ How to Run

1. Download or clone this repository.
2. Open `Hangman_Game.ipynb` using Jupyter Notebook or Google Colab.
3. Run the code cell.
4. Enter one letter when prompted.
5. Continue guessing until you guess the word or use all 6 wrong guesses.

## 🎯 Objective

The main objective of this project is to create a simple interactive game while practicing fundamental Python programming concepts such as loops, conditions, lists, strings, input validation, and randomization.
